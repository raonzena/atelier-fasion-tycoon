# ATELIER — 의류 회사 타이쿤

웹에서 바로 플레이하는 의류 회사 경영 게임 MVP입니다. 정적 파일은 dist/에 있으며, 이 디렉터리를 서버 루트로 제공하면 실행됩니다.

## 플레이

- 사무실 가구와 고양이 직원을 선택하거나 끌어 칸에 배치. 사무실 배치에 따른 제작 보너스는 적용하지 않습니다.
- 5종 의류(티셔츠, 셔츠, 바지, 원피스, 아우터), 5종 스타일과 고객·소재를 조합하고 직원 1~3명을 제작에 배정
- 직원 레벨과 시즌 트렌드를 반영한 예상 성공률, 출시 매출·고객·리뷰 리포트
- 컬렉션 출시마다 봄→여름→가을→겨울 진행, 직원 경험과 연구 포인트 축적
- 2회 출시 시 후드티, 5회 출시 시 가방 발견; 연구 포인트로 리넨과 재생 원단 해금
- 오피스 1–10레벨: 배치 칸 확장, 레벨 4·8에 사무실 배경 전환(최고 단계는 대리석 바닥)
- 게스트 플레이는 새로고침 시 초기화; 선택하면 이 브라우저의 기기에 저장

계정 로그인과 기기 간 동기화는 아직 구현되지 않았습니다. Android MVP는 배포된 웹 게임을 WebView로 엽니다. Sites 배포와 GitHub 저장소는 자동 동기화되지 않습니다.
