# ATELIER — Fashion Company Tycoon

의류 브랜드를 운영하며 컬렉션을 기획하고 회사와 팬덤을 성장시키는 웹 타이쿤 게임 MVP입니다.

## 현재 구현

- 사무실 기반 게임 화면과 팀 캐릭터(디자인·생산·마케팅)
- 타깃, 아이템, 스타일 선택 및 직원 배치
- 출시 결과, 자금, 팬, 회사 레벨 변화
- 게스트 플레이 및 로그인 저장 흐름 데모
- 모바일 반응형 레이아웃

> 현재 배포용 배경 에셋은 웹 배포본에 포함되어 있습니다. 이후 저장소 에셋 구조와 실제 OAuth/DB 저장을 분리해 정리할 예정입니다.
