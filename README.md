# ATELIER — 의류 회사 타이쿤

브라우저에서 바로 플레이하는 의류 회사 경영 게임 MVP입니다. `dist/index.html`을 정적 서버에서 열어 실행할 수 있습니다.

## 현재 플레이

- 사무실의 가구와 직원을 드래그하거나 선택한 뒤 빈 칸에 배치
- 직원이 담당 작업대 근처에 있으면 컬렉션 출시 점수 보너스
- 컬렉션 출시로 자산과 고객 증가
- 오피스 레벨 1–10: 확장할 때마다 새 배치 칸이 열리고, 4·8레벨에 사무실 그림이 바뀜
- 게스트 플레이는 세션 종료 시 초기화. 선택하면 해당 브라우저의 기기 저장 사용 가능

계정 로그인 및 기기 간 동기화는 아직 구현되지 않았습니다. 현재 Sites 배포와 GitHub 저장소는 자동 동기화되지 않으며, 변경사항을 각각 반영해야 합니다.
