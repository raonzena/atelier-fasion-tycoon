# ATELIER — 의류 회사 타이쿤

웹에서 바로 플레이하는 의류 회사 경영 게임입니다. GitHub 저장소에는 정적 파일이 루트에, Sites 작업 폴더에는 dist/에 있습니다.

## 시작과 성장

- 처음 접속하면 회사명을 정합니다. 고객·직원·가구는 모두 0에서 시작하고 초기 자산은 ₩180M입니다.
- 왼쪽 메뉴에서 직원 고용, 가구 구매, 배치 수정, 팀·연구를 엽니다. 구매하거나 고용한 항목은 빈 칸에 먼저 놓입니다. 배치 수정에서 사무실 바닥 방향에 맞는 마름모 격자를 보고 드래그하여 옮길 수 있습니다. 오른쪽 아래 버튼으로 배치를 저장하거나 취소할 수 있습니다.
- 직원 최대 고용 수는 오피스 레벨 1–10에 각각 1–10명, 가구 최대 보유·배치 수는 각각 2–11개입니다. 후보 직원은 오피스 레벨에 맞춰 열립니다.
- 디자인·생산·마케팅 직군에 서로 다른 털무늬와 작업 소품을 가진 고양이 직원이 각각 3명씩 더 있습니다. 직원 고용과 가구 구매 목록은 페이지당 5개씩 표시되며 잠긴 항목에는 자물쇠와 해금 레벨을 보여줍니다.
- 직원을 선택하면 직군·기본 능력·레벨·경험치를 볼 수 있습니다. 사무실 배치에 따른 제작 보너스는 적용하지 않습니다.
- 사무실 화면 왼쪽 위 메뉴에서 관리 기능을 열고, 오른쪽 위에서 회사 레벨·자산·고객과 간단한 오피스·시즌 정보를 봅니다. 오피스 레벨 옆 정보 버튼은 수용 인원·출시 현황·확장 조건을 보여주며, 그 화면에서 확장합니다. 오른쪽 아래 발바닥 버튼으로 새 컬렉션을 만듭니다. 전체 UI는 연한 핑크·노랑·크림 테마를 사용합니다.

## 컬렉션

- 의류 5종, 스타일 5종과 고객·소재를 조합하고 고용한 직원을 제작에 배정
- 직원 능력과 시즌 트렌드를 반영한 예상 성공률, 출시 매출·고객·리뷰 리포트
- 제작 중 예상 성공률이 올라가고 배정된 고양이 직원들이 작업하는 연출이 나옵니다. 출시 성공 시 폭죽, 실패 시 실망한 팀 이미지가 표시되며 결과 리포트에 자산·고객·연구 포인트의 실제 증감과 증감률을 화살표로 보여줍니다.
- 출시마다 봄→여름→가을→겨울 진행, 직원 경험과 연구 포인트 축적
- 2회 출시 시 후드티, 5회 출시 시 가방 발견; 연구 포인트로 리넨과 재생 원단 해금
- 오피스 레벨 1–10: 작은 방과 3×3 배치 격자에서 시작해 사무실 그림과 함께 최대 8×8까지 확장, 레벨 4·8에 사무실 배경 전환. 상위 단계는 대리석 바닥

게스트 플레이는 새로고침 시 초기화됩니다. 선택하면 이 브라우저의 기기에 저장할 수 있습니다. 계정 로그인과 기기 간 동기화는 아직 구현되지 않았습니다. Android MVP는 배포된 웹 게임을 WebView로 엽니다. Sites 배포와 GitHub 저장소는 자동 동기화되지 않습니다.
